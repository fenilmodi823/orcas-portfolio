## Ongoing

A full-stack platform for collecting, validating and analysing continuous glucose
monitoring data from Bluetooth-enabled medical devices.

## What it does

- Architected the full stack — ingestion, validation, analysis and presentation.
- Implemented a **data preprocessing pipeline** handling noise reduction, outlier
  detection and time-series normalisation for **1,000+ daily measurements**.
- Applied statistical methods for trend identification and anomaly detection, generating
  automated reports with confidence metrics and data quality indicators.
- Built visualisation dashboards showing temporal patterns, statistical summaries and
  predictive analytics to support clinical decision-making.
- Integrated data display through **FHIR-based APIs** for healthcare interoperability.

## Stack

Node.js · React · MongoDB · Tailwind CSS · FHIR
